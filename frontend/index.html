WHAT IS BEYOND MAIN?

About

Beyond Main is my personal learning playground and portfolio, where I explore new technologies, improve my software development skills, and turn ideas into working applications. The focus is on backend development, Python, and software engineering practices, with a simple web interface that makes each project accessible and interactive.

Independent Projects

Each application starts as a standalone project developed with its own structure, dependencies, and tests.

FastAPI backend

Applications are integrated into a FastAPI backend and exposed through REST APIs. The backend is containerized using Docker and hosted on Render.

Web Interface

A lightweight web interface allows one to interact with the applications directly. The frontend is hosted on Cloudflare Workers and communicates with the backend through HTTP requests.
